Roadmap

Where the build actually is

Clash Front is pre-alpha. This page tells you what runs today, what's under active build, and what's on the deck for later — no hype, no vaporware.

Live now

Live

Deterministic tick engine

Full canonical phase order (production / consumption / movement / supply / morale / rebellion / battle-spawning / AI). Seeded RNG — no Math.random anywhere. Replay-stable.

Live

March + battle spawning

Parcel-graph movement, HOSTILE + EVASIVE stances, hostile co-location = battle. Owned foreign land is a blockade. Owner rulings resolved via 4 gap patches.

Live

Live 3D battles + hero mode

MOBA engine wired as the battle kernel. Accelerated headless auto-resolve OR live 30 Hz steerable. Hero-mode ⚡ doorway, command channel, replay ring.

Live

Command mode UX

Stances, FLEE with two-press confirm, standing STRATEGY (FLEE_IF_LOSING), Master recall, keyboard shortcuts, help overlay, HP bars, damage floats, kill feed, wave countdown, advisor toasts, respawn indicators.

Live

Fog of war (F1)

Intel memory per governor, ACCURATE / FUZZY / UNKNOWN grades, cluster sight radius, scout sight, decay-to-fuzzy.

Live

Bloodless walk-ins (F2) + wild raids (F3)

Undefended town/settlement walk-ins pop PILLAGE/OCCUPY prompts. Wild raider armies split off lairs, march at players, auto-pillage on arrival.

Live

Economy skeleton (FS3)

Food production, enrichment pools + payout carry, ECON trickle, dev-track investment + raze salvage, wallet ledger, purchase cap.

Live

PG identity + Masters gate

Pentagon Games account login (embedded form → server-side verify). Live sync with Ether Fantasy Masters API — you command only Masters your wallet owns or rents.

Live

Recent battles review

Bounded ring of settled battles per player (fog-filtered). Scrubbable replay panel for accelerated OR live battles. Auto-advance mode.

Live

Retreat ladder + pincer + reinforcement queue

Came-from first, order → adjacent → scatter. Pincered armies fight or abandon. Same-side arrivals at locked hexes queue as reinforcement offers with withdraw API.

Live

Hero-vs-hero card duel (v1)

Card best-of-3 auto-duel using real Master stats + HP + named-artifact spells. Head-shot portraits. Public result surfaced to eligible viewers.

Live

World map + travel routes

12 continents rendered, sky/underworld travel routes (airships, Shaft, Diminishing Stair, Vault-Gate). Kraken drag lanes visible.

Building now

Building

Mass map generation (292k parcels)

Battlefield JSON schema locked, buildSpots spec aligned, playability gate updated (HARD invariants + universal-mode support, CLASH/DOMINION as capability flags). Full 292k mass-gen unlocking next.

Building

Weather × combat

Continent probability cards live in code + deterministic weatherAt() function. Renderer visuals shipped (rain/snow/wind/storm/heatwave). Combat multiplier + per-hit VFX flourishes in flight (MOBA + CF sims mirror the table).

Building

CT ↔ Gold bridge

In-battle Gold cost = plunder rate, formal spec. So 100g spent on an in-battle tower recovers ~100g on victory. Round-trip must math out across battle boundary.

Building

In-battle RTS layer

Build/gather/train mid-fight. Gold mines seeded per parcel. Elite units hire-able in-match. Attacker/defender both spend Gold at valid buildSpots during the match. Master's Sickness modes.

Building

PvE loot pack + boss emit

Wild pack + bosses in CF battles (already spawn on wild land). Match-server emits loot/kills/finds in the result callback → CF settles post-victory.

Building

Deterministic map-floor cutover

Server-authoritative floor + biome + weather in the match start payload. Fixes the "two players on different-colored floors" bug. Same seed → same floor for every viewer, every replay.

Crafting

Farming (food production)

Territory food production per AGRI development level. Populace consumption. Granary caps. Starvation cascade.

Coming

Tax cycle → gold

Periodic tax draws from populace to landowner treasury. Prosperity + morale respond. Ledger entries (double-entry).

Coming

Populace mechanics

Population per land, growth from prosperity, decline from starvation. Rebellion risk model. Enough populace unlocks bigger draft batches + cheaper per-soldier costs.

Coming

Enrichment → populace

Landowner spends CT on enrichment; enrichment pool pays out yield over time. Prosperity nudges up. Populace grows. Draft cap and speed climb. This is the CT-sink incentive for landowners to make their land worth occupying.

Coming
